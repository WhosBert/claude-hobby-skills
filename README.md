## Install a skill

1. Download the ZIP for the skill you want (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP. One ZIP per upload.
3. Turn on code execution in **Settings**, **Capabilities** if it isn't already. Any Claude plan works, including free.
4. Ask a normal question. Claude uses the skill when it fits.

In ChatGPT, personal plans (Free, Plus, Pro) don't have Skills yet: open **Projects**, make a new project, add the skill's `ANY-AI-PASTE-VERSION.txt` to it and type in its instructions: Follow the attached file. On a Business, Enterprise or Edu plan, go to **Skills** (chatgpt.com/skills), click **Add**, choose **Upload from your computer** and pick a ZIP.

In Gemini, download a skill folder (or unzip a ZIP) and upload the folder under **Customize**, **Skills**, **Create**, **Upload**. In Grok, open **Settings**, **Skills** and upload the ZIP, or paste `ANY-AI-PASTE-VERSION.txt` into a **New Skill**.

For Claude Code, Codex, Cursor, Gemini CLI or another coding agent, copy a folder from `skills/` into that tool's skills folder, for example `~/.claude/skills/`.

Or install from the command line with the open skills CLI:

```
npx skills add WhosBert/claude-hobby-skills --skill seed-season-frost-calendar
```

In Claude Code you can also add the whole library as a plugin marketplace: `/plugin marketplace add WhosBert/claude-hobby-skills`.

Using Microsoft Copilot, Perplexity, Meta AI or another chat with no Skills page? Every skill folder has an `ANY-AI-PASTE-VERSION.txt`. Paste it into a new chat, or add it to a ChatGPT Project, Gemini Gem, Perplexity Space or Copilot notebook.
