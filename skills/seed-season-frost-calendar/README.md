# Seed & Season Frost Calendar: a free Claude skill

A small skill that turns your frost date into a seed-starting and planting calendar for up to 8 crops.

- Looks up your average last frost date
- Start indoors, transplant and direct sow dates
- Soil temperature checks built in

Made by [Seed & Season](https://garden.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [seed-season-frost-calendar.zip](../../dist/seed-season-frost-calendar.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
