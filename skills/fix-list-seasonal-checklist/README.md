# Fix List Seasonal Checklist: a free Claude skill

A small skill that builds this season's home maintenance checklist for your home type, systems and climate.

- 8 to 12 tasks for this season only
- DIY or pro for each
- Water-damage prevention built in

Made by [Fix List](https://home.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [fix-list-seasonal-checklist.zip](../../dist/fix-list-seasonal-checklist.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
