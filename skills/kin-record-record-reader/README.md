# Kin & Record Record Reader: a free Claude skill

A small skill that transcribes one record, pulls out every fact, classifies the evidence and writes a citation.

- Faithful transcription with unclear words marked
- Evidence classified fact by fact
- A ready-to-use source citation

Made by [Kin & Record](https://kin.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [kin-record-record-reader.zip](../../dist/kin-record-record-reader.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
