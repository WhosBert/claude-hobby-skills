# Bar Cart Batch Cocktail: a free skill for Claude, ChatGPT, Gemini and Grok

A small skill that turns any cocktail recipe into a big-batch version for a party, with the right water added, bottle counts and how to serve it.

- Any recipe scaled for your guest count
- The right water for stirred, shaken or built drinks
- Bottles to buy and standard drinks per glass

Made by [Bar Cart](https://homebar.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [bar-cart-batch-cocktail.zip](../../dist/bar-cart-batch-cocktail.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using ChatGPT? Personal plans (Free, Plus, Pro) don't have Skills yet: open **Projects**, make a new project, add the skill's `ANY-AI-PASTE-VERSION.txt` to it and type in its instructions: Follow the attached file. On a Business, Enterprise or Edu plan, go to **Skills** (chatgpt.com/skills), click **Add**, choose **Upload from your computer** and pick the same ZIP.

Using Gemini? Unzip it first, then open **Customize**, **Skills**, **Create**, **Upload**, choose **folder** and pick the unzipped folder. Using Grok? Open **Settings**, **Skills**: upload the ZIP if you see Upload, or paste `ANY-AI-PASTE-VERSION.txt` (below the line of equals signs) into a **New Skill**.

Using Claude Code, Codex, Cursor, Gemini CLI or another coding agent? Copy this folder into that tool's skills folder, for example `~/.claude/skills/`.

No Skills page in your app (Copilot, Perplexity, Meta AI)? Open `ANY-AI-PASTE-VERSION.txt` and paste it into a new chat.
