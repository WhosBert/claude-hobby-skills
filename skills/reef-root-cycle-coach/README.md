# Reef & Root Cycle Coach: a free Claude skill

A small skill that walks you through cycling a new tank, reads your test results and tells you when it's safe to add fish.

- Fishless and fish-in plans
- Your readings interpreted
- A simple cycle log

Made by [Reef & Root](https://reef.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [reef-root-cycle-coach.zip](../../dist/reef-root-cycle-coach.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
