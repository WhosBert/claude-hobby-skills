# Life List ID Helper: a free Claude skill

A small skill that asks the right questions about a bird you saw or heard, gives the most likely species with an honest confidence level, and says whether it's safe to count.

- Place and season checked first
- Look-alikes and how to tell them apart
- The one thing to check next time

Made by [Life List](https://birding.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [life-list-id-helper.zip](../../dist/life-list-id-helper.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
