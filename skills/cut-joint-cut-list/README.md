# Cut & Joint Cut List: a free Claude skill

A small skill that turns a simple project (box, shelf, bookcase, bench, frame) into a cut list and a board-foot or plywood estimate.

- Parts grouped by assembly
- Board feet with waste allowance
- Plywood sheet count with kerf

Made by [Cut & Joint](https://wood.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [cut-joint-cut-list.zip](../../dist/cut-joint-cut-list.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
