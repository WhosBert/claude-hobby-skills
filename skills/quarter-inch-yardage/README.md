# Quarter Inch Yardage Calculator: a free Claude skill

A small skill that works out backing, binding and batting for any quilt, plus strips and yards for a set of cut pieces.

- Backing pieced the cheaper way
- Binding strips and yardage
- Math shown, rounded up

Made by [Quarter Inch](https://quilt.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [quarter-inch-yardage.zip](../../dist/quarter-inch-yardage.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
