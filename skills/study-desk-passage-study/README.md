# Study Desk Passage Study: a free Claude skill

A small skill that builds a one-page study sheet for a single passage, ready for sermon prep or a Bible study.

- Context, genre and structure
- Key words and cross-references
- Main idea options to rewrite

Made by [Study Desk](https://pastor.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [study-desk-passage-study.zip](../../dist/study-desk-passage-study.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
