# Next Rung Resume Check: a free skill for Claude, ChatGPT, Gemini and Grok

A small skill that checks your resume against one job posting: which key terms match, which bullets need a result or a number, and what to remove for US and Canadian employers.

- Matched and missing terms from the posting
- Three bullets rewritten with your real results
- US and Canada conventions: no photo, no age

Made by [Next Rung](https://jobs.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [next-rung-resume-check.zip](../../dist/next-rung-resume-check.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using ChatGPT? Personal plans (Free, Plus, Pro) don't have Skills yet: open **Projects**, make a new project, add the skill's `ANY-AI-PASTE-VERSION.txt` to it and type in its instructions: Follow the attached file. On a Business, Enterprise or Edu plan, go to **Skills** (chatgpt.com/skills), click **Add**, choose **Upload from your computer** and pick the same ZIP.

Using Gemini or Grok? Open **Skills** at gemini.google.com or grok.com and upload the same ZIP.

Using Claude Code, Codex, Cursor, Gemini CLI or another coding agent? Copy this folder into that tool's skills folder, for example `~/.claude/skills/`.

No Skills page in your app (Copilot, Perplexity, Meta AI)? Open `ANY-AI-PASTE-VERSION.txt` and paste it into a new chat.
