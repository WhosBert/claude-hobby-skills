# Home Room Week Planner: a free Claude skill

A small skill that builds one realistic homeschool week for all your kids, with a minimum-day backup.

- Together and independent blocks
- Parent never needed by two kids at once
- A minimum-day plan

Made by [Home Room](https://homeschool.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [home-room-week-planner.zip](../../dist/home-room-week-planner.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
