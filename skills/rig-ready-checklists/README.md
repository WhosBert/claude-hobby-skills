# Rig Ready Checklists: a free Claude skill

A small skill that builds departure and arrival checklists for your exact rig, ready to print.

- Only the steps that fit your rig
- Hitch and tire checks built in
- Fits on one page

Made by [Rig Ready](https://rv.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [rig-ready-checklists.zip](../../dist/rig-ready-checklists.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
