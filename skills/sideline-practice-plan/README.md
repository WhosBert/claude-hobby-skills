# Sideline Practice Plan: a free Claude skill

A small skill that writes one timed, kid-first practice plan for your sport, age group, space and equipment.

- Timed plan with drills and cues
- No more than 3 kids waiting
- Easier and harder versions

Made by [Sideline](https://coach.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [sideline-practice-plan.zip](../../dist/sideline-practice-plan.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
