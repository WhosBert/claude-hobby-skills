A small skill that turns your messy notes into a read-aloud recap plus a list of open threads, clues and NPC changes.

- Open threads and clues tracked
- Contradictions flagged, not hidden

Made by [Session Zero](https://gm.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [session-zero-session-recap.zip](../../dist/session-zero-session-recap.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
