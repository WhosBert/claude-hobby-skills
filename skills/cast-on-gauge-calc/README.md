# Cast On Gauge Calculator: a free Claude skill

A small skill that turns your swatch into gauge, shows how big your project will really be, and works out how many skeins to buy.

- Your real finished size
- Needle change or new cast-on count
- Skeins to buy, with a spare

Made by [Cast On](https://knit.whatiflabs.ai/?utm_source=github&utm_medium=referral&utm_campaign=free-skills), part of [What If Labs](https://whatiflabs.ai/projects/skill-stores).

## Install it

1. Download [cast-on-gauge-calc.zip](../../dist/cast-on-gauge-calc.zip) (don't unzip it).
2. In Claude on the web or desktop, open **Customize**, then **Skills**, click **+**, choose **Upload a skill** and pick the ZIP.
3. Make sure code execution is on in **Settings**, **Capabilities**. It works on any Claude plan, including the free one.
4. Ask Claude something in plain words. It picks the skill up on its own.

Using Claude Code instead? Copy this folder into `~/.claude/skills/`.
